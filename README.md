# National_Rainfall_USA_NASA_GPM
National-scale rainfall monitoring, trend, drought (SPI) and extreme-event analytics for all 50 U.S. states + DC, built on NASA GPM IMERG V07 in Google Earth Engine. Includes Theil–Sen &amp; Mann–Kendall trends, ETCCDI indices, colorblind-safe maps, and CSV/GeoTIFF export.
